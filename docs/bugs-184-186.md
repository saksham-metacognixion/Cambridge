## Root causes

- **184.** `composite.py extract` kept the old live cut-out's outline and scale. Where that outline ran past the bottom of the
  client file, the warp had no source pixels and filled them black. Who We Are, FAQs, KSA About and Your Opinion Matters show it.
  The cut-outs' last rows had a luminance of 1-6, against 39-222 a few rows up.
- **185.** `extract` drew the people at **our** old live scale (0.72x-1.23x the client's). `pill_place.py` then centred the shared
  pill stack on those people, so people and pills were scaled and placed independently: 3-189 screen px off the client file at
  1440. Media Hub had no pill spot at all, so it used the default placement. The five banners already on `extract_full` (Speech,
  Inpatient, Paediatric Care, Palliative, Why Global) matched because that mode takes the client's scale and reads the pill spot
  off the client canvas.
- **186.** Both old live cut-outs are cut flat by their own file edge: the wheelchair on Homecare and the woman on Find a Doctor.
  `bleed: "end"` hid that cut by pushing the people past the viewport edge, which also cut the figures. The page also put every
  people box 72 live px from the stage edge and 10 px below the banner, whereas the client files put each picture at its own spot:
  Homecare 198 px in, Find a Doctor 79 px.

## What changed

- `tools/banners/composites.json`: every non-`new` banner (35 entries) now has `"full": true`. Homecare Global and Find a Doctor
  also have `"extend": true`.
- `tools/banners/composite.py` `extract_full`:
  - `extend` takes the client's own key past the old file's end edge, so the whole wheelchair and the whole woman come back.
  - The pill rows are no longer cut out of the translucent key. That cut tore the client's own fades into streaks, for example the
    Inpatient blanket end. The client's pixels are kept there; the page draws the same gradient and pill stack at the same spot.
  - Halo cap (`FULL_HALO`): the old outline never reaches more than 4 composite px past the client's keyed subject. This removes a
    pale band where the old file was cut wider: KSA Homecare, the In-School coat, the Ventilation bed rail.
  - Thin blue-green horizontal slivers under 9 px tall are removed in the key strip and on the pill geometry. These are stroke
    edges that the background estimate misses, on Homecare, Contact and Cerebral Palsy. The physiotherapy band and lanyards stay.
  - `frame_place()` writes `end` (live px from the frame's end edge to the people box) and `drop: 0` (the people stand on the
    frame bottom, as in the files) to `banner-art.json`. `extract_new` writes the same for Media Hub.
- `tools/banners/pill_place.py`: leaves `full` / `new` entries alone (their pill spot comes off the canvas). Media Hub is no longer
  skipped. With every composite banner on `full` / `new`, a run now places nothing and says so; the `pillBox()` default for
  banners without a client file is unchanged.
- `src/lib/banner-art.ts`: optional `end` and `drop` fields.
- `src/components/shared/BannerArt.astro`:
  - The desktop inset is `var(--bend, 72)`. `--bend` is set only for entries with `end`; every other banner renders as before.
  - The drop is `art.drop ?? 10` (Home 5).
  - Tablets only (690-1023): `margin-inline-end` = the pill stack's end overhang. Several client-scale cut-outs are narrower than the
    stack, which then ran up to ~55 px off screen.
- `src/data/banner-art.json`: 36 entries changed (w/h/pills/end/drop; `bleed` removed only from `global:care/heroes/home-healthcare`
  and `global:doctors-page/banner`). Insurance, International, the six hospital pages and every non-composite banner are unchanged.
- 35 re-cut assets under `src/assets/**-cutout.webp` (incl. the 4 named in Bug 184 and the 6 KSA ones in `regions/sa/`).

No copy, links, forms, page data, animations or other styling changed.
