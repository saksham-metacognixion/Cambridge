## How the banners were cut
`tools/banners/composite.py extract_full` needs numpy/OpenCV and the 16 Oct reference set (`_bg.png`, `_ref/`), none of which are on
this machine. `tools/banners/client_cutout.py` (new) does the same job in pure Pillow:
- It keys like Bug 213 (`conditions_cutout.py`): only background connected to the outside goes, so white thobes and coats stay opaque.
- It crops and places like `extract_full`: subject box + 4/5 px, down to the frame bottom, output at 2x live px.
- `w`, `h`, `pills`, `end` and `drop: 0` are read off the canvas, so the pill stack lands where the client file draws it
  (`pills = [w + end - 623.1, h - 449.4]`).
- Pill mask: `node tools/banners/pillmask.mjs`. Output: lossless WebP via sharp.
