## Tool: `tools/banners/client_cutout.py`
Three causes of the edge residue, found by tracing the composite-resolution mask at each stroke crossing:
1. **Pill mask too wide.** It was dilated +-3 rows; it sits within 1 row of the drawn strokes. Light-blue scrubs lie on the
   bg -> sky-blue stroke line (residual 11 <= 14), so the flood bit 2-3 px into the cloth up to 3 rows off each stroke. Now +-2.
2. **Background model off by up to 7.** The left/right linear blend predicted (205,214,221) where the gradient is (198,210,218) (LTC,
   beside the sleeve). With T = 7, pure-gradient px failed the test and stayed on the outline as pale nubs. New
   `local_background()`: the key runs once, the gradient is measured from the px it reached (background connected to the
   outside, never cloth), and the key runs again.
3. **Stroke rows.** New `bridge_strokes()` rebuilds each pill-stroke run (mask +-4 rows) from the rows just above and below it:
   - The outline position is interpolated, so a slanted edge stays slanted. A per-column copy left a straight piece and a step.
   - Stubs in the open go, and stroke-wide bites in cloth are filled.
   - Where the outline runs *along* a stroke (forearm, fist), a sliver is dropped only when it is clearly nearer the stroke
     colour pills.svg draws there than the figure's colour. A navy-dark fold under a sky-blue stroke stays cloth.
   - Edge px take the figure's colour interpolated along the outline. Cloth deeper inside is never recoloured.
   - A px cleared by the bridge stays cleared only if it joins real background; enclosed ones are put back.

Each fix was checked on a contact sheet of every stroke/outline crossing (client file | cut over red), 31-36 per file, and on a
whole-image diff against the previous tool's output. Only edge px changed: 200-900 px per file, plus one real background pocket
(neuromuscular).
