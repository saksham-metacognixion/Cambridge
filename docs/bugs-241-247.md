## Method
1. `tools/banners/client_cutout.py` (final version from Bugs 238-240: two-pass background, pill strokes bridged from the rows
   above and below) keys each client file. It removes only background connected to the outside, with the pill strokes taken
   out of the key before matting.
2. **New:** `tools/banners/cut_to_entry.py` runs that key at composite resolution and resamples ONCE onto the people box a
   `banner-art.json` entry implies (fractional composite px). An entry can stay as it is with no sub-pixel residual. A
   whole-pixel paste left up to 0.25 live px residual. That misregisters fine texture (ghutra check, dress print): International
   rendered 1.95 % off with the paste vs 0.22 % exact.
3. **New:** `tools/banners/edge_matte.py`: the key's mask runs about 1 composite px wide. The outermost px are opaque but mostly
   gradient, which shows as a pale line along dark garments and a pale ring where a navy pill stroke passes behind the people.
   Each outermost px is unmixed against the interior colour and the gradient (alpha only goes down). It skips white cloth on
   the pale gradient (ill-conditioned there), thin parts (crutches, fingers, hair) and px that are not a colour mix.
   Render-back: neutral (RTA: 596 px worse vs 630 better, scattered single px).
4. Lossless WebP (sharp). Re-running steps 2-3 reproduces the installed RTA file exactly on every visible px.

```
node tools/banners/pillmask.mjs /tmp/pillmask.png
python3 -I tools/banners/cut_to_entry.py "<client.png>" /tmp/pillmask.png '{"w":..,"h":..,"end":..,"drop":0}' /tmp/raw.png
python3 -I tools/banners/edge_matte.py "<client.png>" /tmp/raw.png <entry_box from the line above> /tmp/cut.png
```
